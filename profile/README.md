# 株式会社横森製作所（YOKOMORI MFG. Co., LTD.）

**From idea to reality. ── もっと、心が動く空間へ。**

横森製作所は、鉄骨階段の設計・製作・施工を専門とする「階段屋」です。
1951 年の創業以来、オフィスビルや公共施設、商業施設から個人住宅まで、日本の建築物の階段をつくり続けてきました。
お客様のご要望を形にする「実現力」を何より大切にしています。

## 主な事業

- 鉄骨階段（横森式鉄骨化粧階段・Z55-FRC 階段・各種鉄骨溶接階段）
- らせん階段・装飾階段
- 階段用手すり・各種手すり
- 建築用金属工事
- インテリア階段・住宅用階段
- 階段リニューアル工事
